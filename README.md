# Simple Interest Calculator

## Description

A simple shell script that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal = Initial amount
- Rate = Rate of interest
- Time = Time period

## Example

Principal = 10000  
Rate = 5%  
Time = 2 years

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = 1000

## How to Run

Run the following command:

```bash
bash simple-interest.sh
